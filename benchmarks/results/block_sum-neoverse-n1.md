# `block_sum` on an Arm host

`python benchmarks/bench_block_sum.py --gpu` on cfl-test-bench, an 80-core
Ampere Neoverse-N1 (aarch64), pinned to 16 cores (`taskset -c 16-31`). It
ran aocore 0.1.3 with NumPy 2.5.3 and CuPy 14.2.0, driver 580. Times are
microseconds per call. "0.1.2" is the old multi-axis reduction, and
"makewfs f=2" the factor-2 shortcut makewfs kept before 2.0.

On this host `block_sum` beats the makewfs shortcut in 23 of 24 cases. That
includes CPU float32 1024², the one case it lost on x86. The exception, CPU
float64 240² at factor 2, is 4% slower (61 vs 59 µs), within run-to-run noise.
That supports dropping the shortcut in makewfs 2.0.
